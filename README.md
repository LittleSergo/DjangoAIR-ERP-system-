# DjangoAir ERP system

## План роботи:

1. Створити та налаштувати проект.
2. Створити та налаштувати додаток 'erp_system':
3. Написати моделі.
4. Фейкові дані.
5. Написати темплейти, форми, views та urls для інтерфейсу персоналу. Сторінки 
додавання та відміни рейсів(пілоти отримують листа що їх назначили на політ, або 
про відміну), додавання та видалення менеджерів, літаків та пілотів, сторінка 
гейт менеджера для реєстрації посадки пасажирів, та сторінка чек-ін менеджера
для реєстрації пасажирів.
6. Верифікація квитків.
7. Написати темплейти, форми, views та urls для інтерфейсу користувачів реестрації, 
підтвердження реестрації, логіну, виходу з аккаунту, особистого кабінету, редагування 
профілю, сторінки з покупки та оплати квитків, та самостійного чек-іну пасажирів.
8. Емейл верифікація.
9. Додати celery email нагадування про найближчі рейси для пасажирів та пілотів, 
звільнення місць після завершення рейсу.
10. Додати API.
